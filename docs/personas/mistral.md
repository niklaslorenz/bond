# Mistral

Mistral currently supports the following capabilities:

- [Generation](./default-options.md#generation)
- [Summarization](./default-options.md#summarization)
- [Thought Condensation](./default-options.md#thought-condensation)
- [TTS](./default-options.md#tts)
- [Memory](./default-options.md#memory)

All of these capabilities have the default configuration options.
